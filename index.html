Projects

  • English Premier League Data Machine Learning Analysis

    Machine learning analysis of English Premier League data for predictive insights. Capstone project for my Intro to Machine Learning course at UMD. I independently analyzed EPL data using various machine learning models to predict match outcomes and team performance. I cleaned and structured several seasons of data, engineered features like home advantage and goal differential, and converted categorical variables. I applied models including logistic regression, decision trees, random forests, and KNN, using cross-validation to optimize performance and avoid overfitting. This project reflects my ability to manage end-to-end data workflows—from preprocessing and visualization to modeling and evaluation. It also highlights my independence, long-term planning, and interest in real-world ML applications. I used Python extensively with pandas, scikit-learn, and Matplotlib. https://mohidbasha.github.io/Premier-League-Data-ML-Analysis/

  • Web Scraping for Indigenous Tribal Data

    During my internship at the Indian Health Service, I developed Python tools to collect and structure public health data for 6,500+ Indigenous Tribal groups. Using Selenium, BeautifulSoup, and pandas, I built resilient scraping scripts that handled diverse webpage structures and layout changes. I automated the collection of health statistics, tribal classifications, and demographic data from federal and nonprofit sources. I organized this data into clean, structured formats to support analytics and mapping—streamlining access for public health officials and researchers. This project demonstrates my technical skills, attention to ethical data use, and commitment to using technology for social impact.

    https://github.com/mohidbasha/VSFS-IHS

  • Business Proposal: AI Chatbots Assistance to Enhance Student Learning

    For a professional writing course, I developed a proposal to implement AI chatbots in ELMS-Canvas to support student learning. The chatbots would be tailored to each course and trained on its materials, offering quick access to definitions, explanations, and lecture topics. A prototype tested in CMSC335 provided a model for scaling. The proposal targeted the University’s Division of IT and considered stakeholders like Student Affairs and General Counsel. I built a logical argument (logos), supported by research on digital learning, to show how this solution could improve educational access and engagement. This work showcases my ability to align technical ideas with institutional needs and reinforces my interest in educational technology and AI.
